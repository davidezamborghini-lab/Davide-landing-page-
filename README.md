# DANOTREAL — Power Bank Landing Page

Premium concept landing page with a **real-time WebGL 3D scroll animation** showing a magnetic power bank attaching to a smartphone.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Tech
React 19, Vite, Three.js, React Three Fiber, Drei, CSS. The 3D motion is driven by native scroll progress.

## Important before selling
- The smartphone and power-bank models are intentionally approximate concept models, **not manufacturer-accurate CAD assets**.
- Obtain original high-resolution product images / 3D files from the supplier to upgrade the model.
- Verify actual iPhone model compatibility, magnetic alignment, safety certificates and all charging claims with supplier documents.
- Contact CTA is a placeholder email; replace it with a working brand email or form.
- No checkout, inventory or payment integration is configured.
